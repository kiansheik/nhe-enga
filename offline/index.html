Instalar aplicativo Android

O aplicativo Android guarda os downloads como arquivos do aplicativo. No navegador, o sistema pode limitar o armazenamento; mantenha esta página aberta durante downloads grandes.

Carregando opções…

Uma página de fonte aberta com internet também fica salva. Páginas nunca baixadas não estarão disponíveis sem conexão. Apagar os dados do navegador ou desinstalar o aplicativo remove os downloads.
