# Agent Notes

Start here for compact repository context before editing.

- `current-state.md`: current cleanup state and active cautions.
- `repo-map.md`: source, generated, and served-path map.
- `open-questions.md`: unresolved repo questions.
- `served-assets.md`: static assets and data expected by the hosted site.
- `log.md`: short chronological work log.
- `session-handoffs/`: handoffs from prior sessions.
